# 打鳥（暫名）

透過長鏡頭拍野鳥的瀏覽器模擬遊戲原型。設計文件在 `docs/GDD.md`，技術規劃在 `docs/TECH_PLAN.md`。

## 開發

```
npm install
npm run dev        # http://localhost:5173
npm test           # 相機數學與狀態的單元測試
npm run build      # 型別檢查 + 打包到 dist/
```

## 目前進度

- M0 完成：Vite + TypeScript + three.js，程序化低多邊形場景，toon 材質，紙片斑鳩。
- M1 完成：焦距 / 光圈 / 快門 / ISO / 對焦距離可調，觀景窗曝光模擬，即時物理景深，手震模型，ISO 噪點，紙框 HUD。
- M2 完成：按快門以 1920×1280 渲染照片（48 取樣景深、主體與手震動態模糊、鉛筆描邊抖線、紙張顆粒），
  連拍 / 緩衝區 / 記憶卡 / 黑屏 / 觀景窗延遲，照片存進 IndexedDB，相簿頁（G）。
  斑鳩貼圖由 Gemini 生成後去背，流程見 `docs/ART_PIPELINE.md`。

## 操作

| 動作 | 輸入 |
|---|---|
| 轉雲台 | 滑鼠（點畫面鎖定） |
| 變焦 | 滾輪 |
| 對焦環 | 右鍵拖曳 |
| 光圈 / 快門 / ISO | Q E / A D / Z C |
| 放下相機看全景 | Tab |
| 時段 / 天氣（除錯用） | 1 2 3 4 / 5 6 |
| 快門（按住連拍） | 左鍵 |
| 相簿 | G |
| 讓鳥跳一下（測動態模糊） | B |
| 換器材（除錯用） | 7 入門 / 8 全幅 100-500 / 9 旗艦 500 f/4 懸臂雲台 |
| 說明與除錯數字 | H |

瀏覽器主控台可用 `window.__game` 切換器材，例如 `__game.setGear('L4','B3','S4')`。
