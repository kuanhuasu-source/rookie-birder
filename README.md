# 打鳥（暫名）

透過長鏡頭拍野鳥的瀏覽器模擬遊戲原型。設計文件在 `docs/GDD.md`，技術規劃在 `docs/TECH_PLAN.md`。

## 開發

```
npm install
npm run dev        # http://localhost:5173
npm test           # 相機數學與狀態的單元測試
npm run build      # 型別檢查 + 打包到 dist/
```

## 目前進度

- M0 完成：Vite + TypeScript + three.js，程序化低多邊形場景，toon 材質，紙片斑鳩。
- M1 完成：焦距 / 光圈 / 快門 / ISO / 對焦距離可調，觀景窗曝光模擬，即時物理景深，手震模型，ISO 噪點，紙框 HUD。
- M2 完成：按快門以 1920×1280 渲染照片（48 取樣景深、主體與手震動態模糊、鉛筆描邊抖線、紙張顆粒），
  連拍 / 緩衝區 / 記憶卡 / 黑屏 / 觀景窗延遲，照片存進 IndexedDB，相簿頁（G）。
  斑鳩貼圖由 Gemini 生成後去背，流程見 `docs/ART_PIPELINE.md`。
- M3 完成：珠頸斑鳩五段狀態機（飛入、降落、靜止、小動作、跳枝、起飛、飛離），側面 / 四分之三面 / 起飛三張紙片切換與鏡像，
  兩個停棲點（枝頭、石頭），出現間隔與停留時間，出現前 2.5 秒程序化鳴叫，照片記錄鳥的狀態與頭部角度。
- M4 完成：四大項評分（對焦與銳利度 30、曝光 25、構圖與背景 25、姿態與時機 20）、封頂規則、星等、一句話建議；
  拍照時用小尺寸遮罩讀回算遮擋、主體亮度、背景雜亂，射線量背景距離；拍後提示、代幣、相簿分數卡。
- M5 完成：第零課教學十步（找鳥、拉近、對焦、太亮、太暗、牠在動、放對位置、看懂分數、牠要飛了、下課），
  黑板提示、卡住 20 秒補圖解、粉筆輔助線（對焦點、三分線、視線箭頭、曝光三角）、腳本化斑鳩、Esc 跳過、T 重上。
- 測試邀請：`docs/PLAYTEST.md`，相簿頁可匯出不含圖片的 JSON 紀錄。
- 鳥種擴充：五種公園鳥（珠頸斑鳩、白頭翁、麻雀、綠繡眼、紅嘴黑鵯）依權重輪流出現，各有行為節奏、體型與叫聲；
  貼圖由 `scripts/gen_sprites.py` 用 Gemini 生成、去背、標眼睛、算反照率，眼睛標錯用 `scripts/fix_eye.py` 補。

- 進度系統：代幣、器材、圖鑑存在瀏覽器 localStorage。圖鑑（K）每種鳥四格（停棲、動作、起飛、飛行）自動收最高分照片，
  新鳥種 +15、新格子 +10 代幣；扭蛋（U）30 代幣一次，8 次內保底稀有以上，重複退幣；裝備頁換上抽到的器材即時生效。

- 關卡系統：兩章四關（公園上午 / 黃昏、溪流清晨 / 陰天），每關三個任務各點名一個攝影觀念，完成前一關任一任務解鎖下一關；
  每個場景三個機位（描述中性，光線與距離自己判斷）；8 分鐘計時與記憶卡容量；收工（X）結算最佳照片、任務與代幣。
- 第二章溪流：翠鳥、白鶺鴒、小白鷺，水道、溪中石、枯枝與蘆葦的場景。

- 攝影知識（I）：12 篇課本式文章，從成像原理、曝光三角、光圈與景深、快門與動態、ISO、焦距與等效焦距，
  到對焦系統、測光與曝光模式、光線、構圖、支撐與防手震、野鳥攝影倫理，附手繪風 SVG 圖解（相機剖面、光圈葉片、景深、快門簾、感光元件、太陽方位、懸臂雲台）。
- 器材插畫：14 張無品牌的紙片貼紙風器材圖（`scripts/gen_gear.py` 用 Gemini 生成），顯示在裝備頁與扭蛋結果。

- 自動對焦：機身決定階段，鏡頭決定速度。入門機只有手動；中階 APS-C 單點 AF（半按時對中心測距一次）；
  全幅連續追焦（半按期間持續重取）；旗艦鳥眼 AF（鳥在畫面內就鎖眼睛）。中心沒有東西會拉風箱。
  半按用空白鍵（手機是 AF 鈕長按），合焦有提示音，中心框變綠。教學中一律手動。

- 驚嚇系統：每隻鳥有警戒值，雲台轉太快、連拍太久、距離比容忍距離近都會累積，安靜時消退。六成牠會抬頭跳開，
  滿了飛到更遠的停棲點，再滿一次離場。鳥種各有敏感度（斑鳩 0.6、翠鳥 1.3）。觀景窗左上有警戒表。
- 配件：迷彩布（警戒累積減半）、躲鳥帳（四分之一，鳥更常來）、1.4x / 2x 增距鏡（焦距倍增、光圈少一到兩格、對焦變慢、略柔）。
  可同時裝多個，增距鏡只能裝一個。電子快門機身（全幅以上）連拍的驚嚇較小。

## 手機與平板

橫向使用。單指拖動轉雲台、雙指捏合變焦、拖動下方對焦刻度對焦；右邊橘色大鈕是快門（按住連拍），
左邊有放下相機、相簿、穩住與選單，光圈 / 快門 / ISO 讀數旁有 − + 鈕。教學提示會自動改成觸控的說法。

## 操作

| 動作 | 輸入 |
|---|---|
| 轉雲台 | 滑鼠（點畫面鎖定） |
| 變焦 | 滾輪 |
| 對焦環 | W / S 或方向鍵（按住持續轉）、Shift + 滾輪、右鍵拖曳、Ctrl + 移動滑鼠 |
| 光圈 / 快門 / ISO | Q E / A D / Z C |
| 放下相機看全景 | Tab |
| 半按快門自動對焦（機身有 AF 時） | 按住空白鍵 |
| 穩住（手震減半、雲台變慢） | 按住 Shift |
| 減少畫面晃動（不影響照片評分） | V |
| 時段 / 天氣（除錯用） | 1 2 3 4 / 5 6 |
| 快門（按住連拍） | 左鍵 |
| 相簿 | G |
| 圖鑑 / 裝備與扭蛋 / 攝影知識 | K / U / I |
| 收工 / 選關 | X |
| 重上第零課 / 跳過教學 | T / Esc |
| 讓鳥現在出現 / 讓鳥起飛（除錯用） | N / B |
| 換器材（除錯用） | 7 入門 / 8 全幅 100-500 / 9 旗艦 500 f/4 懸臂雲台 |
| 說明與除錯數字 | H |

瀏覽器主控台可用 `window.__game` 切換器材，例如 `__game.setGear('L4','B3','S4')`。
