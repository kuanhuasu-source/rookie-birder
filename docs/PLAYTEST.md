# 邀請朋友測試 MVP

## 一句話邀請（可直接貼）

> 我在做一個「小白打鳥」的瀏覽器小遊戲：用長鏡頭拍野鳥，曝光、對焦、構圖都是真的。
> 大約 15 分鐘，開這個網址用電腦玩就好，不用安裝：https://kuanhuasu-source.github.io/rookie-birder/
> 玩完回我三句話：哪裡卡住、哪裡爽、最想要什麼。謝謝！

## 測試者需要知道的

- 電腦 + 滑鼠（觸控板能玩但不順），Chrome 或 Edge 最穩，Safari 也可。
- Mac 觸控板：對焦用 W / S 鍵或 Shift 加兩指滑動，不用右鍵拖曳。
- 第一次進去會直接上「第零課」，大約 5 分鐘，跟著黑板做就好。
- 之後鳥會自己來，等牠、拍牠，按 G 看照片與分數。
- 照片只存在自己的瀏覽器裡，不會上傳。

## 想從測試得到什麼（依優先順序）

1. **教學卡關點**：第零課哪一步停最久、看不懂哪一句提示。
2. **手感**：長焦時的晃動是「真實」還是「煩」？對焦環的靈敏度？
3. **評分可信度**：拿到分數時覺得合理嗎？哪一次覺得被冤枉？
4. **想繼續玩的理由**：什麼時候想關掉、什麼時候想再拍一張。

## 回饋怎麼收

- 最省事：請他們在相簿頁按「匯出紀錄」，把下載的 JSON 連同三句話傳給你。
  JSON 裡有每張照片的設定、分數、建議與教學完成時間，沒有圖片。
- 想要結構化：開一個 Google 表單，問題就用上面的四點，各一題開放式加一題 1 到 5 分。
- 看著玩：找兩三個人視訊共享螢幕玩前 10 分鐘，不要出聲，只記他們停在哪裡。

## 這一版刻意沒有的

- 扭蛋、圖鑑、多鳥種、多關卡。測試者會問，先記下他們問的順序，那就是優先順序。
- 手機版。

## 發布流程

每次推到 main，GitHub Actions 會自動建置並部署到 Pages。
第一次需要在倉庫 Settings → Pages 把 Source 設成「GitHub Actions」。
