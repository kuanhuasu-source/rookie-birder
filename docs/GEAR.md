# 器材階梯與 Canon / Nikon / Sony 對照

遊戲裡的器材是抽象的等級，數值在 `src/data/gear.json`。下表把每一級對到三家目前主流的實體產品，
讓玩家與測試者知道「這一級大概是什麼」。型號以 2025 年前後的產品線為準，新機發表後請更新。
對照是「等級相當」，不是規格完全一致。

## 使用方式：換器材時會發生什麼

- **快門、ISO、對焦距離都保留**，不會因為換器材歸零。ISO 超過新機身上限時夾到上限。
- **焦距夾進新鏡頭的範圍**：100-500 換到 55-250 時焦距變 250；換到 500 f/4 定焦就是 500。
- **光圈不能大於新鏡頭在該焦距的最大光圈**：f/4 換到 100-500 的 500mm 端會變 f/7.1；原本縮到 f/8 則保留。
- **定焦鏡滾輪不變焦**，畫面會提示；要改構圖請換機位或裝增距鏡。
- **最近對焦距離**：500 f/4 是 4 m、600 f/4 是 4.5 m，比這近的鳥對不到焦，對焦刻度也會隨鏡頭改變。
- **APS-C 機身的視角 = 焦距 ×1.6**，HUD 會顯示「250mm (等效 401)」；換到全幅視角會變寬，這是真實的取捨。
- **對焦速度**：`afSpeed` 數字越小越快（L1 0.9 慢、L3 0.35 快、L5 0.2 極快），增距鏡會把它乘上 1.5 或 2.2 倍變慢。
- **增距鏡只能裝一個**：裝 2x 會自動卸下 1.4x。焦距與光圈的顯示都已含增距鏡效果（600 f/4 加 2x 顯示 1200mm f/8）。
- 裝備頁每件器材下方有一行規格，拿到才看得到。

## 升級體感對照

| 從 → 到 | 玩家會感覺到 |
|---|---|
| L1 → L3 | 對岸的翠鳥終於拉得到，對焦跟得上牠轉頭，1/125 手持也不糊 |
| B1 → B3 | 林子裡 ISO 6400 還是乾淨的，連拍不黑屏，觀景窗不延遲 |
| S0 → S4 | 1/250 也能穩穩拍夜鷺，追飛鳥時雲台跟得上 |
| 裝 2x 增距鏡 | 焦距夠了，但 f/14 在陰天根本拍不了 |

## 備註

- 遊戲數值是為了手感設計的抽象值，不是官方規格。噪點係數、緩衝張數、延遲幀數都可以在 `gear.json` 調。
- Nikon 目前沒有與 R7 / α6700 完全對位的高階 DX 機身，暫以 Z50 II 代表 B2；若之後有新機再更新。
- 第三方鏡頭（Sigma、Tamron）在 Sony E 與 Nikon Z 上選擇很多，對照表只列一個代表。
